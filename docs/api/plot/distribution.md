# Size distribution

Heatmaps, per-scan curves and 3-D views of dN/dS/dV/dlogDp matrices, plus
lognormal curve fitting. Input is the matrix `RawDataReader('SMPS' | 'APS')`
returns (index = time, columns = diameters). Usage:
[Visualization](../../guide/visualization.md#advanced-charts).
